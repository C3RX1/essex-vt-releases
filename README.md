# Essex VT test releases

Assetto Corsa free roam drift map recreating Essex Junction, Vermont.

Download the track ZIP and optional feedback kit from [Releases](https://github.com/C3RX1/essex-vt-releases/releases).
Install the track by dropping the ZIP into Content Manager. Custom Shaders Patch is required for the track's CSP features and street-name HUD.

The server is being tested locally; public connection details will follow once forwarding is verified.

Map data: OpenStreetMap contributors (ODbL). Elevation, imagery and land cover: Vermont Center for Geographic Information (VCGI), VT Open Geodata.
Poles, lights, signs and wall colours: Mapillary (CC BY-SA 4.0). Distant landscape: USGS 3DEP (public domain).
Font: Overpass (SIL OFL). Track author: c3rx.

These releases contain the custom track and feedback materials. Use the cars supplied with your own Assetto Corsa installation.
